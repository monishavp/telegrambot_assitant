# 🤖 AI-Powered Telegram Bot – Golden Blush Assistant

## 🚀 Overview

The **AI-Powered Telegram Bot** is a smart virtual assistant designed for salon businesses like **Golden Blush**. It combines **FAQ automation, keyword-based intelligence, and motivational engagement** into a single chatbot that interacts with users in real time via Telegram.

This project is part of a **100 AI Projects Challenge**, focusing on building practical, deployable AI systems.

---

## ✨ Features

### 💬 Smart FAQ Assistant

* Answers customer queries instantly
* Handles:

  * Services (facial, hair, etc.)
  * Pricing
  * Offers
  * Location & timings

### 🎯 Keyword-Based NLP

* Detects user intent using keyword matching
* Lightweight and fast (no heavy ML required)

### 💡 Motivational Quote Generator

* Responds with random motivational quotes
* Triggered by:

  * `motivate me`
  * `quote`

### 📱 Telegram Integration

* Real-time messaging
* Easy to use interface
* Accessible anywhere

---

## 🧠 How It Works

1. User sends a message via Telegram
2. Bot processes input using:

   * Keyword matching logic
   * Rule-based response engine
3. Bot returns:

   * FAQ response OR
   * Motivational quote

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ai-telegram-bot.git
cd ai-telegram-bot
```

### 2. Install Dependencies

```bash
pip install python-telegram-bot
```

### 3. Add Bot Token

Replace in code:

```python
TOKEN = "YOUR_BOT_TOKEN_HERE"
```

---

## ▶️ Run the Bot

```bash
python smart_bot.py
```
